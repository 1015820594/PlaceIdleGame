# 天龙挂机 - 放置爬塔游戏

## 1. Concept & Vision

一款以《天龙八部》世界观为背景的放置挂机爬塔游戏。玩家扮演一位江湖侠士，在无尽的塔层中挑战越来越强大的敌人。游戏强调数值成长的乐趣，参考经典MMO的战斗数值体系，将复杂的属性计算简化为直观的伤害数字，让玩家在离线时也能持续获得装备和属性的提升。

**核心体验**：紧张刺激的战斗演出 + 数值碾压的爽感 + 永无止境的挑战目标

## 2. Design Language

### 2.1 Aesthetic Direction
**武侠水墨风格** - 将中国传统水墨画元素与现代游戏UI结合，营造出古典江湖的意境。

### 2.2 Color Palette
```
Primary: #8B4513 (古铜棕 - 武器/装备)
Secondary: #1a1a2e (玄墨黑 - 背景主色)
Accent: #e94560 (血红 - 伤害/暴击)
Gold: #ffd700 (金色 - 顶级奖励)
Jade: #00d9ff (青玉 - 属性加成)
Background: #0f0f23 (深渊黑)
Text: #eaeaea (素白)
Muted: #6c6c8a (灰墨)
```

### 2.3 Typography
- **标题**: "Ma Shan Zheng" (中文毛笔字体)
- **正文**: "ZCOOL XiaoWei" (站酷小薇)
- **数字**: "Orbitron" (科幻感数字显示)
- Fallback: "Microsoft YaHei", "SimHei", sans-serif

### 2.4 Motion Philosophy
- 攻击动作：快速出击 + 收招，带有残影效果
- 伤害数字：向上飘出 + 逐渐消失，暴击时带有震屏效果
- 升级特效：金色光芒从底部升起
- 切换层数：淡入淡出的过渡动画
- 背景：缓慢飘动的云雾效果

## 4. Features & Interactions

### 4.1 核心战斗系统

**玩家属性系统**（参考天龙八部公式）：

| 属性 | 说明 | 成长 |
|------|------|------|
| 力量 | 外功攻击 | 10点 = 10外功攻击 |
| 灵气 | 内功攻击 | 10点 = 10内功攻击 |
| 体力 | 血量&外防 | 10点 = 100血量 + 5外防 |
| 定力 | 气量&内防 | 10点 = 50气量 + 5内防 |
| 身法 | 命中/闪避/会心 | 10点 = 20命中 + 10闪避 + 2%会心 |

**战斗公式**：
- 外功伤害 = 外功攻击 / 20 - 目标外防 / 50
- 内功伤害 = 内功攻击 / 15 - 目标内防 / 50
- 会心伤害 = 伤害 × 2.0 (暴击)
- 打怪加成 = 伤害 × 5

**属性伤害**：
- 冰/火/玄/毒属性攻击
- 属性伤害 = 属性值 × 1.0 × [1 - (目标抗性 - 减抗下限)/100]
- 抗性：每20层+5点对应属性抗性

### 4.2 爬塔系统

**层数难度曲线**：
- 每5层怪物属性倍率+10%
- 每20层解锁新属性抗性
- 每50层精英怪（双倍属性+特殊技能）
- 每100层BOSS（当前最高难度）

**怪物生成**：
- 怪物为"裸装玩家模板"：无装备、无技能
- 怪物根据层数获得属性点分配
- 怪物属性点 = 基础属性 × (1 + 层数 × 0.02)

### 4.3 战斗流程

**回合制自动战斗**：
1. 玩家先攻（普攻 + 技能循环）
2. 5个怪物依次攻击玩家
3. 玩家死亡后根据当前层数获得奖励
4. 重新从当前层数开始

**技能系统**（简化版）：
- 技能1：雷霆一击 - 造成300%伤害
- 技能2：铁布衫 - 3秒内减伤50%
- 技能3：回春术 - 恢复20%最大生命
- 技能冷却：每个技能独立CD

### 4.4 奖励系统

**每层通关奖励**：
- 金币：100 × 层数
- 经验：50 × 层数（用于升级属性点）

**升级系统**：
- 每次升级获得5点自由属性点
- 可自由分配到5大属性

**装备系统**（后期扩展预留接口）：
- 装备通过挂机时间自动获得
- 装备提供额外属性加成

### 4.5 宠物系统（预留）
- 后期可携带宠物助战
- 宠物拥有独立属性和技能

## 5. Component Inventory

### 5.1 角色卡片组件
- 显示：头像、名称、等级、血条、属性
- 状态：普通、受伤（闪烁红边）、暴击（震屏）、死亡（灰度化）
- 怪物卡片额外显示：击杀进度条

### 5.2 伤害数字组件
- 普通伤害：白色数字向上飘
- 暴击伤害：金色数字 + "爆！"字样 + 震屏
- 属性伤害：根据属性类型显示对应颜色
- 治疗数字：绿色向上飘

### 5.3 进度条组件
- 血条：绿→黄→红渐变
- 经验条：蓝色发光效果
- 层数进度：显示距离下一难度阶段

### 5.4 属性面板组件
- 五维雷达图显示
- 详细数值列表
- 升级按钮 + 加点操作

### 5.5 战斗日志组件
- 滚动显示最近10条战斗信息
- 颜色区分伤害来源
- 自动清空重复信息

## 6. Technical Approach

### 6.1 技术栈
- **前端**：原生HTML5 + CSS3 + JavaScript
- **动画**：CSS3动画 + requestAnimationFrame
- **存储**：LocalStorage（存档）
- **无框架依赖**：纯原生实现

### 6.2 游戏架构
```
Game
├── Player (玩家数据)
│   ├── baseStats (基础属性)
│   ├── bonusStats (装备加成)
│   ├── skills (技能)
│   └── level (等级)
├── Monster (怪物系统)
│   ├── generateMonster(floor) (根据层数生成)
│   └── monsters[] (5个怪物实例)
├── Battle (战斗系统)
│   ├── calculateDamage() (伤害计算)
│   ├── checkHit() (命中判定)
│   └── checkCrit() (暴击判定)
├── Tower (爬塔系统)
│   ├── currentFloor (当前层数)
│   └── maxFloor (最高层数)
└── SaveSystem (存档系统)
    ├── save() (保存)
    └── load() (读取)
```

### 6.3 性能优化
- 使用requestAnimationFrame进行游戏循环
- DOM元素复用，避免频繁创建销毁
- 伤害数字使用对象池
- 离线收益使用增量计算
